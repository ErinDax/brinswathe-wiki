## 这是什么

**Brin's Wathe**（简称 **b-w**，模组 id `brinswathe`）是 **BRIN 列车** 整合包的专属扩展模组，在 wathe 基础上新增：

- **22+ 个特色角色**（傀儡师、恐怖分子、轰炸机、牛仔、拾骨师……）
- **角色专属商店**（自毁装置、身份提示、解毒剂、炸弹等）
- **丰富机制**（傀儡控制、爆炸链、牛仔决斗、替身转移、挂机踢出……）
- **按角色定制的能力价格/冷却/持续时间配置**

# 角色总览

b-w 共 **25 个特色角色**（通过 `BrinRoles` 注册并加入 wathe 角色池）。角色名与玩法一句话取自 `zh_cn.json`（`announcement` 键），id 与 `BrinRoles.java` 一致。

| 角色 id | 中文名 | 阵营 | 玩法一句话 |
|---|---|---|---|
| `puppeteer` | 傀儡师 | 杀手 | 操控你的猎物为你所用 |
| `stunt_double` | 替身演员 | 平民 | 模仿他人，并代替模仿对象承受致命伤害 |
| `medium` | 灵媒 | 平民 | 花费金钱短暂通灵，与死者对话获取信息 |
| `conspirator` | 合谋者 | 平民 | 开局就知道谁是杀手并帮助杀手获胜；能捡枪但无法开枪 |
| `watchman` | 生存专家 | 平民 | 看见被捕兽夹困住的玩家，并帮助他们脱困 |
| `beast_trapper` / `beastcatcher` | 捕兽者 | 杀手 | 布下致命的捕兽夹，让猎物无法移动 |
| `nightmare` | 梦魇 | 杀手中立 | 感染所有沉睡者；成为唯一存活者即可获胜 |
| `illusionist` | 幻术师 | 杀手 | 制造幻影分身来迷惑敌人 |
| `sniper` | 狙击手 | 杀手 | 瞄准猎物，从墙壁另一侧送出致命一击 |
| `berserker` | 狂战士 | 独立中立 | 购买疯魔后永久无敌并可使用本能，成为唯一存活者即可获胜 |
| `archivist` | 档案员 | 平民 | 识别伪造尸体，封存尸体防止被溶解或复活 |
| `boneharvester` | 拾骨师 | 杀手 | 击杀后尸体延迟显现，剔骨为自己叠加护盾 |
| `compensator` | 代偿者 | 独立中立 | 以命换命，击杀你的人自食其果 |
| `gambler` | 赌徒 | 独立中立 | 押注阵营，押中则该阵营获胜时你跟随获胜 |
| `penitent` | 赎罪者 | 杀手中立 | 亲手处决指定身份的目标，达成即独立获胜 |
| `terrorist` | 恐怖分子 | 杀手中立 | 被枪杀时引发爆炸，爆炸消灭足够玩家则你存活 |
| `bomber` | 炸弹客 | 杀手 | 埋下地雷，把炸弹贴到猎物身上 |
| `zhangshi` | 张师 | 杀手 | 吞下雪兹，在毒发前完成一次击杀 |
| `mortician` | 入殓师 | 杀手 | 把自己伪装成尸体，等待猎物走近 |
| `avenger` | 复仇者 | 平民 | 亲眼目睹他人死亡后短暂获得本能（可以捡枪） |
| `stalker` | 变态 | 平民 | 对准一名玩家使用技能开始追踪，位置实时显示 |
| `cowboy` | 牛仔 | 平民 | 点名一位存活玩家发起牛仔对决，一局限用一次 |
| `valentina` | 瓦伦西娜 | 平民 | 预知眼可抵挡一次枪杀或刀杀，消耗层数换取本能与永久缓慢 |
| `subverter` | 策反者 | 独立中立 | 开局 30 秒内赌上性命策反目标，声明阵营正确则随其新阵营获胜 |
| `inspector` | 安检员 | 平民 | 一次性让全员缴械，期间所有人（包括自己）无法使用物品 |

!!! note "说明"
    - 捕兽者在源码注册 id 为 `beastcatcher`，配置文件中使用 `beast_trapper`，两者等价。
    - `conspirator`（合谋者）为 v3.0 由原「接线员」`eavesdropper` 重做而来，旧 id 已不再使用。
    - 每个角色的详细能力可在左侧对应页面查看；数值见 [可配置项](config.md)。

# 角色总览

b-w 共 **29 个特色角色**（通过 `ModRoles` 注册并加入 wathe 角色池）。角色名与玩法一句话取自 `zh_cn.json`（`announcement` 键），id 与源码一致。

## 平民阵营（11）

| 角色 id | 中文名 | 玩法一句话 |
|---|---|---|
| `stunt_double` | 替身演员 | 模仿他人，并代替模仿对象承受致命伤害 |
| `medium` | 灵媒 | 花费金钱短暂通灵，与死者对话获取信息 |
| `conspirator` | 合谋者 | 开局就知道谁是杀手并帮助杀手获胜；能捡枪但无法开枪 |
| `watchman` | 生存专家 | 看见陷阱与地雷并解救被困者；平民只剩你时进入生存时刻 |
| `archivist` | 档案员 | 识别伪造尸体，封存尸体防止被溶解、复活或制成傀儡 |
| `avenger` | 复仇者 | 目睹他人死亡后短暂获得本能（可以捡枪） |
| `stalker` | 变态 | 对准一名玩家使用技能开始追踪，位置实时显示 |
| `cowboy` | 牛仔 | 点名一位存活玩家发起牛仔对决，一局限用一次 |
| `valentina` | 瓦伦西娜 | 预知眼可抵挡一次枪杀或刀杀，消耗层数换取本能与永久缓慢 |
| `inspector` | 安检员 | 一次性让全员缴械，期间所有人（包括自己）无法使用物品 |
| `zhuimu` | 坠姆 | 放下木船强行掳走一名玩家，用铁斧处决 |

## 杀手阵营（10）

| 角色 id | 中文名 | 玩法一句话 |
|---|---|---|
| `puppeteer` | 傀儡师 | 把尸体做成傀儡为你操控，可回收、可自爆 |
| `beast_trapper` / `beastcatcher` | 捕兽者 | 布下致命的捕兽夹，让猎物无法移动 |
| `illusionist` | 幻术师 | 制造幻影分身来迷惑敌人 |
| `sniper` | 狙击手 | 瞄准猎物，从墙壁另一侧送出致命一击 |
| `boneharvester` | 拾骨师 | 击杀后尸体延迟显现，剔骨为自己叠加护盾 |
| `bomber` | 炸弹客 | 埋下地雷，把炸弹贴到猎物身上 |
| `zhangshi` | 张师 | 吞下雪兹，在毒发前完成一次击杀 |
| `mortician` | 入殓师 | 把自己伪装成尸体，等待猎物走近 |
| `grappler` | 钩锁师 | 甩出钩锁把远处玩家拉到身边并眩晕 |
| `half_spirit` | 半灵体 | 穿过一格厚的墙或门，出现在另一侧 |

## 杀手中立阵营（3）

| 角色 id | 中文名 | 玩法一句话 |
|---|---|---|
| `nightmare` | 梦魇 | 感染所有沉睡者；成为唯一存活者即可获胜 |
| `penitent` | 赎罪者 | 亲手处决指定身份的目标，达成即独立获胜 |
| `terrorist` | 恐怖分子 | 被枪杀时引发爆炸，爆炸消灭足够玩家则你存活 |

## 独立中立阵营（5）

| 角色 id | 中文名 | 玩法一句话 |
|---|---|---|
| `berserker` | 狂战士 | 购买疯魔后永久无敌并可使用本能，成为唯一存活者即可获胜 |
| `compensator` | 代偿者 | 以命换命，击杀你的人自食其果 |
| `gambler` | 赌徒 | 押注阵营，押中则该阵营获胜时你跟随获胜 |
| `subverter` | 策反者 | 开局 30 秒内赌上性命策反目标，声明阵营正确则随其新阵营获胜 |
| `spy` | 间谍 | 猜测其他玩家的身份，猜对足够人数即独立获胜 |

!!! note "说明"
    - 捕兽者在源码注册 id 为 `beastcatcher`，配置文件中使用 `beast_trapper`，两者等价。
    - `conspirator`（合谋者）为 v3.0 由原「接线员」`eavesdropper` 重做而来，旧 id 已不再使用。
    - 每个角色的详细能力可在左侧对应页面查看；数值见 [可配置项](config.md)。

# 策反者（subverter）

> **中立阵营** · v3.0 新增

## 策反

**开局 30 秒内**，准心对准一名玩家并按技能键，选择将其「**策反为杀手**」或「**策反为平民**」。

| 情况 | 结果 |
|---|---|
| 选择的阵营与目标原阵营**相同** | **你死亡** |
| **超时**未选择 | **你死亡** |
| 选择的阵营与目标原阵营**不同** | **策反成功**，你随他的**新阵营**获胜 |

## 胜利条件

策反成功后，**跟随被策反玩家的新阵营获胜**。

!!! tip "玩法提示"
    开局 30 秒是生死关口：必须立刻锁定目标，并判断对方的真实阵营。猜错即死——这是本角色的核心赌局。

# 捕兽者（beast_trapper / beastcatcher）

按下技能键可以花费一定金额布置**捕兽夹**

**捕兽夹**放下后若无人踩中，**三分半后会自动消失**（v2.5.0 起不再永久存在）

被**捕兽夹**夹住的玩家将一直被定住直到死亡

杀手无法触发**捕兽夹**

可在商店购买**额外捕兽夹**，购买之后无视**捕兽夹**数量限制直接在脚下放置**捕兽夹**

生存专家（*来源：Brin's Wathe*）可以看到捕兽夹

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能花费 `skill_cost` | 25 |
| 技能冷却 `skill_cooldown_seconds` | 120 |
| 同时存在上限 `trap_limit` | 1 |
| 额外捕兽夹价格 `extra_trap_price` | 150 |
| 每夹住一人奖励 `trap_catch_reward` | 50 |

!!! info "版本说明"
    v2.1.0：技能花费改为 25；v2.5.0：捕兽夹改为非永久，存在一段时间后消失。

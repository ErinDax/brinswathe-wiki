# 半灵体（half_spirit）

> **杀手阵营** · v3.1 新增

## 主动 · 穿墙

面朝身前一格半以内的墙、门或玻璃按下技能键，穿过面前这一格方块，出现在另一侧。

## 判定细则

- **只能穿透一格**：墙后紧挨着第二层方块时穿不过去（贴在墙面上的薄板这类薄装饰不算第二层）
- **落点必须安全**：另一侧要有能站下的空间、脚下要有地面，并且在列车范围内；对面悬空或在列车外时不会穿过去
- 对面地面比你低时会直接落到地面上，**最多低三格**
- 方向按你面朝的东南西北四个正方向计算，**只能水平穿透**，不能穿地板和天花板
- 半格高的矮台阶不算障碍；另一侧紧贴着床、座椅这类矮家具时会直接站到上面
- 坐着、躺着或被眩晕时无法使用
- 技能冷却 **120 秒**，**没有穿过去不进入冷却**
- 开局安全期内无法使用

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能冷却 `skill_cooldown_seconds` | 120 |
| 刀价 `shop_prices.knife` | 100 |
| 疯魔 `shop_prices.psycho_mode` | 300 |

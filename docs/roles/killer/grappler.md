# 钩锁师（grappler）

> **杀手阵营** · v3.1 新增

## 主动 · 钩锁

准心对准 **16 格**内的一名存活玩家按下技能键，甩出钩锁把对方拉到自己身边，被钩中的玩家**眩晕 2 秒**。

## 判定细则

- **钩锁不能穿透方块**：隔着墙、玻璃或关着的门钩不到人
- 被拉的玩家同样不会穿过方块：**一格高以内的障碍**会被直接拖过去，更高的障碍会把人挡在半路，**眩晕照常生效**
- 正在睡觉或坐着的玩家会被直接拉起来
- **无法钩走**的对象：被坠姆木船困住的玩家、踩中地雷的玩家、正在瞄准的狙击手；伪装成尸体的入殓师也钩不到
- 技能冷却 **90 秒**，但**没有钩中人不进入冷却**
- 开局安全期内无法使用

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 钩锁范围 `hook_range` | 16（范围 1–32）|
| 眩晕时长 `skill_duration_seconds` | 2 |
| 技能冷却 `skill_cooldown_seconds` | 90 |
| 刀价 `shop_prices.knife` | 100 |
| 疯魔 `shop_prices.psycho_mode` | 300 |

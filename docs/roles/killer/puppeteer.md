# 傀儡师（puppeteer）

傀儡师对准尸体按下技能键可以将尸体制成**傀儡**

**被档案员（*来源：Brin's Wathe*）封存的尸体无法制成傀儡**

打开背包界面会显示已制成的**傀儡**，点击**傀儡**图标立刻开始操控**傀儡**，操控期间**本体**无法移动

**傀儡**自带一把刀与一个撬棍

每个**傀儡**累计可以操控 **60 秒**，累计到第 **45 秒**时傀儡会露出破绽，时间用完后报废

## 回收机制（v3.1 新增）

操控期间再次按下技能键可以**回收傀儡**，回收的傀儡**保留剩余时间**，可以再次操控，背包界面的傀儡图标会显示各自的剩余时间

无论回收还是报废，都需要等待 **60 秒**才能再次操控傀儡

**傀儡**报废会导致**本体**获得 **10 秒**高亮，**回收则不会**；如果**傀儡**被击杀还会额外获得 **15 秒**缓慢

报废的**傀儡**会直接消失，不会留下尸体

**本体**死亡**傀儡**将立刻消失

## 自爆

当傀儡师在商店购买**自爆**之后，操控的**傀儡**死亡会产生一次以自己为中心的 **5×5×5** 爆炸（向四周各 **2 格**），**无视护盾**

!!! warning "注意"
    购买自爆后，操控期间按下技能键会**引爆傀儡**，而不是回收。

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能冷却 `skill_cooldown_seconds` | 200 |
| 单傀儡累计操控时长 `skill_duration_seconds` | 60 |
| 回收/报废后再操控冷却 `return_cooldown_seconds` | 60 |
| 自爆装置价格 `self_destruct_price` | 350 |
| 自爆半径 `self_destruct_range` | 2（向四周各格数，即 5×5×5）|
| 自爆粒子预警 `particle_delay_seconds` | 45 |
| 报废后本体高亮 `exposed_glow_seconds` | 10 |
| 傀儡被击杀后缓慢 `killed_slowness_seconds` | 15 |
| 刀价 `shop_prices.knife` | 100 |
| 疯魔 `shop_prices.psycho_mode` | 300 |

!!! info "版本说明"
    v3.1：默认刀价下调至 100、加回疯魔、新增傀儡回收机制；v2.5.0：自爆范围调整并加回手雷。

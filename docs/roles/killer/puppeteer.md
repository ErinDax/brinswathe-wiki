# 傀儡师（puppeteer）

傀儡师对准尸体按下技能键可以将尸体制成**傀儡**

打开背包界面会显示已制成的**傀儡**，点击**傀儡**图标立刻开始操控**傀儡**，操控期间**本体**无法移动

**傀儡**自带一把刀与一个撬棍

**傀儡**持续时间为60秒，第45秒时傀儡会露出破绽

**傀儡**在非自我回收的情况下报废都会导致**本体**获得10秒高亮，如果**傀儡**被击杀还会额外获得15秒缓慢

已经使用的**傀儡**会直接消失，不会留下尸体

当傀儡师在商店购买**自爆**之后，操控的**傀儡**死亡会产生一次以自己为中心的3x3x3爆炸

**本体**死亡**傀儡**将立刻消失

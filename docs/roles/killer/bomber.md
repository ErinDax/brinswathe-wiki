# 炸弹客（bomber）

## 该角色为**猫陌**的赞助角色，感谢陌总支持

炸弹客无法买刀，但是手雷价格会降低

可以购买**炸弹**，**地雷**

**炸弹**：手持炸弹对他人右键可以放人身上，被放置炸弹玩家15秒后收到提示：距离炸弹爆炸还有30s，玩家可以右键他人传递炸弹，炸弹爆炸范围2*2*2。

**地雷**：手持地雷右键在脚下放置地雷，地雷踩上去不能动，动就炸，但只会炸死踩上去的那个人，踩上去有声音提示

**炸弹**及**地雷**手持时他人不可见

生存专家（*来源：Brin's Wathe*）看不到地雷，但可以解救踩中地雷的玩家

如果炸弹客的爆炸影响到了恐怖分子（*来源：Brin's Wathe*）恐怖分子也会爆炸

杀手阵营不会触发炸弹

# 梦魇（nightmare）

梦魇拥有一层初始护盾，可以看到睡觉的玩家

可以对睡觉的玩家进行**播种**，每**播种**一位玩家多一层护盾，上限两层

**梦魇时刻开始前**，被**播种**的玩家无法杀死梦魇；**梦魇时刻开始后**，被**播种**的玩家也能杀死梦魇

你可以给存活玩家发放睡觉任务

当杀手阵营全员死亡之后，若梦魇还存活会触发**梦魇时刻**

**梦魇时刻**会给梦魇发放刀、杀手本能以及杀手商店

**梦魇时刻**前梦魇随杀手一起结算，**梦魇时刻**后梦魇独立结算

**梦魇时刻**获胜条件：播种所有存活玩家或者杀死所有人

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能冷却 `skill_cooldown_seconds` | 60 |
| 强制发放睡觉任务冷却 `forced_sleep_task_cooldown_seconds` | 200 |

!!! info "版本说明"
    v2.0.0：梦魇改为偏杀手阵营（杀手中立）；v2.5.0：梦魇时刻之后，被播种的玩家可以击杀梦魇。

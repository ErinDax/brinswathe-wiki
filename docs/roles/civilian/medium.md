# 灵媒（medium）

**可以捡起左轮手枪**（v2.1.0 起改为可捡枪，同时移除了灵媒的枪商店）

花费金钱可以短暂的**通灵**

**通灵**期间你可以与死者对话获取信息

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能花费 `skill_cost` | 200 |
| 技能冷却 `skill_cooldown_seconds` | 120 |
| 通灵时长 `skill_duration_seconds` | 8 |
| 左轮售价 `shop_prices.revolver` | 500 |

!!! info "版本说明"
    v2.1.0 起灵媒可以捡枪，且不再拥有专属枪商店。

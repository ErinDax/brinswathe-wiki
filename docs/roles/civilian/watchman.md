# 生存专家（watchman）

**拥有永久的夜视**

你可以看到被**捕兽夹**（*捕兽者，来源 Brin's Wathe*）以及**地雷**（*炸弹客，来源 Brin's Wathe*）困住的玩家

你可以看到**捕兽夹**，你会被**捕兽夹**夹住；你看不到**地雷**，但是**地雷**无法困住你

花费一定数量的金钱对准该玩家按下技能键可以解救被困或**身绑炸弹**的玩家

自己被困住时，没有对准其他被困玩家按下技能键会解救自己

## 生存时刻（v3.1 新增）

**平民阵营只剩你时**（合谋者不算）进入**生存时刻**，所有人都会收到提示

再存活 **{survival_seconds} 秒**，**平民阵营直接获胜**

开局安全期和牛仔决斗期间，**生存时刻不计时**

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能花费 `skill_cost` | 150 |
| 技能冷却 `skill_cooldown_seconds` | 30 |

!!! info "版本说明"
    v2.5.0：默认技能花费改为 150；v3.1：新增生存时刻机制，技能可解救身绑炸弹的玩家。

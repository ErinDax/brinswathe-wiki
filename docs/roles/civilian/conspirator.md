# 合谋者（conspirator）

> **平民阵营** · v3.0 由原「接线员」（eavesdropper）重做而来

开局即可知道谁是杀手，并帮助杀手获胜。

**合谋者**在场时，杀手会收到提示：「**这班车上有你的合谋者**」。

## 主动技能

花费 **150** 与选定的杀手**连线 15 秒**，期间**能捡枪但无法开枪**。

## 查验与结算

- 被**义警**查验时，显示为**好人**
- 平民可以**枪杀**合谋者
- **乘客获胜**时，合谋者默认死亡

## 默认配置

| 配置项 | 默认值 |
|---|---|
| 技能花费 `skill_cost` | 150 |
| 技能冷却 `skill_cooldown_seconds` | 200 |
| 连线时长 `skill_duration_seconds` | 15 |

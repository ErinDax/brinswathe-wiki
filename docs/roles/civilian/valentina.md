# 瓦伦西娜（valentina）

## 该角色为**猫陌**的赞助角色，感谢陌总支持

> **平民阵营** · v3.0 新增

## 被动 · 预知眼

每层**预知眼**可以抵挡一次**枪杀**或**刀杀**。

开局 **0 层**，上限 **2 层**，每完成 **4 个任务**恢复 1 层；**满层时完成的任务不计入**。

## 主动技能

消耗 **2 层**预知眼，获得 **10 秒本能**，同时获得**缓慢 I**（缓慢持续到本局结束）。

之后每使用一次，**缓慢再提升一级**。

!!! tip "玩法提示"
    预知眼是保命资源，且满层后做任务不累计——想留着主动技能发挥，就要控制层数不要提前顶满。主动技能属于「越用越亏」的滚雪球机制：用本能换探查能力，代价是永久减速。

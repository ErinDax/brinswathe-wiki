# 牛仔（cowboy）

在攒够足够的金钱之后可以选择一位玩家发动**西部对决**（*选择方式为打开背包选择玩家头像*）

**西部对决**期间玩家只能使用牛仔左轮，并且无法使用主动技能以及被动技能（*未完全测试，但狂信者被动不受影响*）

当**西部对决**场地只剩一名玩家存活时**牛仔时间**结束，所有玩家返回游戏区域

当两名玩家在**西部对决**限时时间内未完成对对方的击杀，则两人都死亡

**牛仔时间**的所有掉落物均会在**牛仔时间**结束之后传送到牛仔进**牛仔时间**之前的位置

**牛仔时间**不会承受开枪惩罚

**⚠️注意⚠️：如果你开启了牛仔并想游玩西部对决，请为西部对决准备一个场地，Y轴在118格往上即可，随后请去配置文件里设置两位玩家的出生点坐标以及旁观者出生点坐标，两位玩家默认朝向为东/西，建议东/西向建造场地，当然你也可以直接用列车。**

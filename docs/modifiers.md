# 词条

词条（modifier）是 wathe 的修饰符系统，在开局时随机分配给玩家。以下是 b-w 新增的词条。

可用 `/setEnabledModifier` 关闭某个词条（关闭后不再随机分配），或用 `/rolemodifierblacklist` 为指定职业屏蔽某个词条。

## 丧葬（funeral）

拥有该词条的玩家可以 `Shift + 右键` 尸体进行**搬运**，再次 `Shift + 右键` 将尸体**放下**。

**搬运期间**：

- 无法使用任何物品
- 无法交互
- 移动速度 **-50%**

## 流浪（vagrant）

**空手**按住 `Shift + 右键` 脚下的地面，就能**就地躺下睡觉**，不需要床。

- 躺着时和睡床一样**计入睡觉任务**
- 按 **Esc** 起身
- 右键床、门、活板门等能交互的方块时仍是原本的操作
- **无法躺下**的情况：搬运尸体时、被困在船上时、牛仔对决期间

!!! tip "快捷操作"
    屏幕提示为 `Shift+右键：就地睡觉`。

## 惩罚（punishment）

!!! warning "这不是随机词条"
    惩罚由系统判定触发，不会被随机分配。

**触发条件**：在开局数秒内**掉出列车**，下一局将受到惩罚。

**惩罚效果**：

- 本局你**必定成为制毒师**
- 本局**全场都能看到你的高亮**，直至死亡

> 提示文本：「你受到了惩罚：本局全场都能看到你的高亮，直至死亡」
